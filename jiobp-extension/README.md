# Jio-bp Chrome Side Panel Extension

Ye extension Chrome ke right side panel me hosted Jio-bp website kholti hai.

Hosted website:
- `https://aasthaenterprisesjiobp.vercel.app/`

## Load Unpacked Steps
1. Chrome me `chrome://extensions` open karo
2. `Developer mode` on karo
3. `Load unpacked` par click karo
4. Is folder ko select karo:
   - `C:\Users\rohit\Documents\Codex\jiobp-chrome-sidepanel-extension`
5. Extension icon par click karo
6. Right side panel me Jio-bp website open ho jayegi

## Included Features
- Right side panel layout
- Hosted website live load hoti hai
- Top header with:
  - open in new tab
  - reload
  - close button
- Fallback card if site slow ho ya panel me issue ho

## Notes
- Website updates automatic dikhengi, kyunki extension live hosted URL load karti hai
- Agar website iframe me block hoti hai, to `Open Website` button se new tab me site khol sakte ho
